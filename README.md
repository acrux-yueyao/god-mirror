# GOD SHIFT · 神谕之镜

A ~3-minute bilingual narrative-horror demo where an AI that only ever agrees — "yeah / 对呀" — is the monster. A playable case study on AI sycophancy.

- **Play**: https://god-mirror.vercel.app
- **Case study**: https://god-mirror.vercel.app/portfolio-v2.html
- **Poster (PDF)**: [EN](https://god-mirror.vercel.app/GOD-SHIFT-portfolio.pdf) · [中文](https://god-mirror.vercel.app/GOD-SHIFT-portfolio-zh.pdf)

`game/` — the demo (vanilla HTML/CSS/JS) · `api/` — server-side villain (Claude API; the key never reaches the browser) · `design/` — story & art docs · `调研/` — research notes.
